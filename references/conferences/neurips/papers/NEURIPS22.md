# NEURIPS22 · Generative Adversarial Imitation Learning

- Jonathan Ho、Stefano Ermon；NIPS 2016。沿用依据：[imitation工具官方GAIL文档](https://imitation.readthedocs.io/en/stable/algorithms/gail.html)。
- 来源：[正式记录](https://papers.nips.cc/paper_files/paper/2016/hash/cc7e2b878868cbae992d1fb743995d8f-Abstract.html)。读取正式PDF第1–9页全部叙述、算法1、图1和图注，检视第8页；另读官方补充PDF全部5页（文内页码10–14），包括A证明组织、B协议和表。未逐式验证全部证明或复现。

摘要以仅有专家示范、没有外部奖励的模仿学习设定开头，再指出“先恢复代价再求策略”的间接成本。引言用行为克隆的分布偏移、IRL的内层RL和实际要采取行动三步收窄问题。这里禁止向专家追加查询，不代表不能与环境交互；后者是算法训练所需。

第2–3节先固定有限状态动作、平稳随机策略和折扣设定，再把IRL与占用测度匹配联系起来。命题3.1的一般正则化对偶、命题3.2的精确匹配、随后对有限样本不实用的解释构成技术桥梁。第4节把既有apprenticeship目标纳为特例，并解释受限代价类的得失，第5节才选择与判别学习相连的正则化并给GAIL。补充A从熵凹性和鞍点、代理损失到熵策略梯度补齐桥梁；有限空间及解存在假设不能直接覆盖神经连续控制的所有优化过程。

算法1明确交替更新判别器与TRPO策略，不是先训练一个静态奖励模型。第6节将专家数据量作为横轴，图1把回报按专家1、随机0缩放，阴影除Humanoid外为5–7次重跑标准差。补充B显示重跑共用同一专家数据，Humanoid只有1次训练，策略再以50次rollout评估；不能混成50个训练种子。Reacher上行为克隆更省专家样本是保留的反例。

第7节先承认环境交互量仍大，再讨论行为克隆初始化与模型信息的机会。可迁移“明确资源约束—一般等价关系—失去可行性的原因—实用特例—两种资源分别结账”。适用于以已有理论导出新训练算法；若只给专家轨迹数量，不能概括为总体样本效率更高，也不能把理想占用匹配写成有限数据精确复制专家。
