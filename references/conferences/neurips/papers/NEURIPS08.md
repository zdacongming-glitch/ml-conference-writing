# NEURIPS08 · Efficient sparse coding algorithms

- Honglak Lee、Alexis Battle、Rajat Raina、Andrew Y. Ng；NIPS 2006。
- 来源：[正式记录](https://papers.nips.cc/paper_files/paper/2006/hash/2d71b2ae158c7c5912cc0bbde2bb9d95-Abstract.html)。读取正式 PDF 全部 8 页叙述、算法 1、证明纲要、表 1–2、图 1–3/图注；检视第 6–7 页图表。无独立附录；未逐行验证算法证明或复现实验。

摘要将计算瓶颈、两个条件凸子问题、速度改善及可研究的神经现象相连。引言先说明稀疏与过完备表征的意义，再将贡献限定到计算效率及所使能的分析，没有把稀疏编码本身重新命名为新贡献。

第 2 节给生成解释、目标和基向量范数约束，明确分别凸而非联合凸。第 3 节先用“固定符号后变成无约束二次问题”的直觉引出 feature-sign，再给算法、两条严格下降引理和有限终止定理；第 4 节从原始基学习问题推导变量更少的对偶。定理的全局保证针对固定基的系数子问题，不能扩到交替学习的联合目标。

第 5 节先比较系数求解的时间和终值误差，再比较两子算法组合的整轮成本；表 1、2 因而回答不同问题。图 1 解释 warm start 在后期迭代的好处；图 2 的大规模基使用的是 epsilonL1，不能误归为 L1 feature-sign 的独占结果；图 3 是端停止及周围抑制刺激的诊断。第 6 节报告的是另项 self-taught learning 工作，不能把其全部分类收益算作当前正式稿已完整展示的实验。

结尾回收算法与所使能的经验研究。适合借鉴“明确子问题—操作直觉—有限保证—分阶段和总成本—使能应用”的顺序。神经反应的定性相容不是生理唯一解释；历史 MATLAB 实现与硬件的速度倍数也不能直接推广到现代求解器。
