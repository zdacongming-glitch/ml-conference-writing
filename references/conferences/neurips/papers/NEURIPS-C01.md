# NEURIPS-C01 · Large Language Diffusion Models

- Shen Nie、Fengqi Zhu、Zebin You、Xiaolu Zhang、Jingyang Ou、Jun Hu、Jun Zhou、Yankai Lin、Ji-Rong Wen、Chongxuan Li；NeurIPS 2025 Main Conference Track。最近已完成届次的校准样本，不称长期经典或获奖文。
- 来源：[正式记录](https://papers.nips.cc/paper_files/paper/2025/hash/48b383b24230e0e6e649d9c98dae4d8c-Abstract-Conference.html)。读正式39页PDF第1–10页全部主文、主图1–3、表1–4及对话，另读第25–34页A与B.1–B.8概率建模、数据、协议、采样、成本和合成数学测试。检视第2、3、6、8、30、32页图表；第35–38页额外案例及第39页明细未全读。

摘要以“核心LLM能力是否依赖自回归”组织模型和结果。引言先用分布拟合目标与自回归因子分解两个公式拆开原则和实现，再提出替代建模的可检验问题。Fisher一致性带无限数据、足够网络与理想优化的脚注；不是已有8B模型能力的定理。图1雷达概览只提供外部模型比较，图3（第6页）才是同训练数据、按计算量排列的对照。

第2节按概率定义、预训练、SFT、推理排列。图2以同一掩码预测器贯穿训练与生成，正文区分随机重掩码的概率过程与实际低置信度启发式；后者不能直接继承所有精确采样解释。附录A把似然界与任意顺序条件学习联系起来，相关理论归于前作，原文的贡献是扩展规模与验证。单次8B训练及SFT无超参数调优也如实说明。

第3节先扩展性、再综合任务、反向诗句、案例。图3拒绝为少量异常点强拟合缩放曲线；1B架构对齐，较大规模是已有7B ARM对8B扩散，最大规模未获同等对照。表1–2标清自评/转引、shot、训练token与SFT/RL差异；外部模型数据不透明，不能归因胜负全由建模范式造成。表4仅496组中文诗句，反向强于GPT-4o不等于通用推理更强。表3颜色显示生成时序，对话是能力案例而非总体通过率。

附录B.4–B.7记录EOS处理、不同任务生成长度、Monte Carlo次数与单A100/批量1计时；图5给质量—吞吐前沿，并保留MBPP落后。第5节明确未对最大规模同数据ARM、公平架构优化、RL对齐与动态长度充分验证。可迁移“拆原则与参数化—可匹配对照—外部现实参照—专门机制任务—协议和成本”；适用于范式可行性研究。结尾自评“高度创新”不作为可复用句式，泛化主张仍应由具体证据范围约束。
