# NEURIPS02 · On Spectral Clustering: Analysis and an algorithm

- Andrew Y. Ng、Michael I. Jordan、Yair Weiss；NIPS 2001，正式会议论文。
- 来源：[正式记录](https://papers.nips.cc/paper_files/paper/2001/hash/801272ee79cfde7fa5960571fee36b9b-Abstract.html)。读取正式 PDF 全部 8 页叙述、算法、假设及图 1；检视第 7 页所有聚类子图。未逐行验证扰动界，未复现实验。

摘要先将缺口拆成算法变体不统一和保证不足，再给简单算法、扰动分析与示例。第 1 节依次比较混合模型及 K-means 的困难、光谱方法已有成功但存在的选择问题、二分图割分析的局限，最后定位同时使用多个特征向量的改动；已有成功没有被写成全部前作失败。

第 2 节先完整列六步算法，随后用非凸簇解释为何最后仍可使用 K-means。第 3.1 节从块对角理想情形说明行归一化的意义，并指出单个特征向量的旋转不唯一性；第 3.2 节再给扰动条件、eigengap 的簇紧密性解释以及定理。条件不是脱离问题的一张符号表。

第 4 节将理论几何用于选择尺度参数。图 1 的 a–g 是不同形状的结果，h 展示嵌入后点，i–l 给具体失败对照；图形承担问题说明和机制直觉，不能据此推出所有数据上的性能排名。初始化与重启次数的差异在脚注交代，应保留比较口径。

第 5 节以 Kernel PCA 的关系和其他谱算法差别结束，没有另加重复贡献清单。可借鉴“理想情形—稳定性—可解释条件—诊断实例”的顺序；适用于有明确理想结构的分析。具体六步流程、已知簇数和尺度搜索并非所有谱聚类稿的固定结构，示例中的非凸形状也不证明普遍鲁棒。
