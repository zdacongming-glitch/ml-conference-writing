# NEURIPS09 · Random Features for Large-Scale Kernel Machines

- Ali Rahimi、Benjamin Recht；NIPS 2007；[2017 官方会册中的 Test of Time Award](https://media.nips.cc/Conferences/NIPS2017/NIPS-2017-Conference-Book.pdf)。
- 来源：[正式记录](https://papers.nips.cc/paper_files/paper/2007/hash/013a006f03dbc5392effeb8f18fda755-Abstract.html)。读取正式 PDF 8 页全部主文叙述、两算法、图 1–3、表 1及附录证明的组织和解释；检视含图的第 3、4、6 页。未逐行审计界或复现。

摘要以显式随机低维映射和线性学习器说明提速思路，再说明近似的是核内积及两类构造。引言的比较轴很明确：前作近似数据的 Gram 矩阵，本篇直接近似核函数；随即用一个内积关系说明改变的对象，再区分训练与评估成本。相关工作继续按大规模核计算中的操作分组。

第 3 节从随机投影接正弦的图解进入，用 Bochner 定理说明采样分布，区分固定点对集中与紧集上的一致近似，再给算法。第 4 节从随机分箱的碰撞概率构造另一种估计器，解释适用核限制；不是给前一种方法换个名称。附录用覆盖网格、平滑性及集中界展开证明路线。

图 1–2 解释随机特征如何近似内积，表 1 同时报测试误差、训练时间及特征数，图 3 分开数据量、特征数对误差和耗时的影响。第 5 页脚注直陈 KDDCUP99 重复样本及 CVM 对排序、参数的敏感性，因此这组时间和精度不能当成无条件优势。Fourier 与 binning 在 Forest 等任务上差别也被保留。

结尾区分已做的分类回归比较与可能的其他核方法用途。可迁移的是先说近似哪一个对象，再连接构造、误差与计算；适合近似算法论文。核近似界不是预测风险保证，紧集和核条件不可删除；历史硬件上的耗时不代表今天所有实现同倍加速，未实验的混合或其他任务也不是现有结果。
