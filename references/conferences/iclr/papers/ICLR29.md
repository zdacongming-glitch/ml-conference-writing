# ICLR29 · Density estimation using Real NVP

- 会议：ICLR 2017，主会。
- 全文来源：[1605.08803](https://arxiv.org/pdf/1605.08803)。
- 实际阅读：主文§1–6全文，图1–6、表1及图表注；PDF pp.1–10。附录条件生成与batch-normalization细节未逐项核验。
- 阅读日期：2026-10-19。
- 以下为独立撰写的结构分析，非论文原文摘抄。

## 摘要的信息选择

以学习、采样、推断、密度四种计算能力定义贡献，再给可逆变换族和图像证据；“exact”指模型内可计算性，不表示模型分布等于数据分布（p.1）。

## 引言的推进

§1明确高维表达能力与可计算性的共同问题，§2按无向、变分、自回归、对抗模型的计算取舍定位；图1用双向映射提前说明主接口（pp.1–3）。

## 方法、直觉与定义的顺序

§3.1给变量变换，§3.2给单个affine coupling，§3.3展示三角Jacobian与同成本逆，再扩mask、交替组合、多尺度与归一化。复杂结构由可检查的简单变换组合而成（pp.3–7）。

## 图表的证据角色

图2核正反计算图，图3/4核mask、squeeze、分层析出；表1将真实密度与变分上界符号区分，并保留test/validation拆分。图5样本与图6插值支持不同定性用途（pp.4–9）。

## 结尾的作用

§5先回收可逆可计算能力，再讨论与VAE/GAN/自回归的互补和可能应用。半监督及强化学习用途仍为建议，未伪装完成实证（pp.9–10）。

## 可迁移规范及条件

可组合变换稿按单元→性质→组合→全模型展开，密度评测交代离散图像加噪、logit等预处理Jacobian。反例：exact inference只是确定潜状态，并非有语义因素识别保证；样本有明显低质量情形，不能由似然可算推出感知质量最好。

## 版本与反例

arXiv v3（2017-02-27），正式主会页眉。原结尾对VAE/GAN不能学高维语义空间的笼统对比不宜迁移；表1也显示PixelRNN/IAF的似然更好，不能改写为全面领先。
