# 无损删改后的统一去水印

本技能按用户指定的方案，在独立无损删改后调用本地 `watermarks-remover`。处理当前任务生成或获准修改的正文。

1. 初稿完成后独立做一遍无损删改；已有成熟句子不强行重写。
2. 找到本机 `watermarks-remover/SKILL.md`，读取 `references/prose.md`，由当前助手做一次忠实语言整理。改善自然表达和节奏，删除残留套语与虚设对立；不恢复刚删的解释，不重复回译或增加新主张。
3. 文件交付先 inspect，再保守清理 Unicode 到独立副本：`python scripts/finalize_text.py <input> --output <new-path>`。适用 TXT、Markdown、LaTeX；默认不删除元数据。
4. 比较原文与输出的公式、代码、变量、目标函数、引用键、标签、数值、条件、实验协议、训练测试信息和必要声明。程序保护部分精确文本，科学含义仍由助手核对；发生漂移则撤销该处修改。
5. 保存前检查 Markdown 公式定界符；保留原件和独立副本，向用户交付选定终稿，不默认贴两份全文。

清理不改算法名、术语、方法标识、数学符号或统计结论，不删除来源归属、版权或所需 AI 使用声明。不能因本次只是语言整理就推断研究全程没有使用 AI。没有问题的文本可以不变。

自然语言整理由当前助手完成，无需安装额外重写服务。没有检测器和对应配置时，不声称已验证消除统计水印、证明人类来源或保证通过检测。本地依赖不可用时完成可做的忠实整理和技术核对，明确未执行的工具步骤；聊天输出不能声称已做文件字节级审计。
