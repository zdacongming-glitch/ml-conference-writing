# 核心术语核验

在不同核心术语首次引入或定义前执行；同一任务同一概念核验一次，定义未变时复用已核验资料。

## 定义先于名称

1. 明确对象、目标、可用信息、训练与评估阶段、数学定义及有效范围。
2. 查方向 `terms.json`、作者提供的一手文献和最邻近研究；可复用其他会议或方向已核验的同一概念。
3. 缺少来源、有歧义、拟新命名或与已知定义不同，强制检索原始定义及代表性用法。术语来源不限定目标会议。
4. 定义等价则采用惯用名称；相关但不等价时保留区别，说明实际继承或扩展。名称频率不能替代定义比较。
5. 确定首选名称、常用缩写与大小写，全文一致复用。不要为避免重复轮换技术近义词，也不为单次普通概念发明缩写。

重点核对泛化、迁移与适配，transductive 与 inductive，linear probe 与 fine-tuning，训练目标、代理目标与随机估计器，遗憾、目标值与参数收敛，以及参数量、FLOPs、延迟、吞吐量和实际耗时。相邻术语不能仅因结果看起来类似就互换。

`robust`、`efficient`、`optimal`、`general` 等要对应明确性质；`zero-shot` 或 `few-shot` 的描述须核对训练、提示、适配与评估时实际使用的信息，不能用更流行名称扩大结论。

没有等价既有概念时使用清楚的描述性名称。有限检索不足以支持首次性声明。检索缺口与待确认定义放在正文外，不在每个定义旁附检索说明。

## 可复用记录

方向 `terms.json` 保存对象 `schema_version`、`topic_id`、`checked_at`、`terms`。每个术语条目含：

- `concept_id`：跨方向可以复用的稳定概念 ID。
- `preferred_term`、`aliases`：惯用首选名称与实际同义名称。
- `definition_scope`：定义、信息与有效范围。
- `distinguish_from`：不能混同的相邻概念。
- `sources`：正式文献身份或 URL，附章节、定义编号或页码。
- `verified_at`：实际核验日期。

共享缓存只保存来自公开来源、已经核验的可复用概念；单稿新构造、未发表定义和专用记号留在项目中。术语或定义发生实质变化时检查受影响记录，保留旧条目及替代原因。
